# IEEE UCF Micromouse Project

We are developing a small, fully autonomous robot to participate in Micromouse competitions. The robot’s goal is to navigate through a maze as quickly and efficiently as possible without any prior knowledge of the maze. This project combines embedded systems, PCB design, pathfinding algorithms, autonomous navigation, control systems, and CAD modeling. The goal is for this to be a beginner-friendly project, and we will help new members learn the necessary concepts to complete the project through hands-on workshops.
